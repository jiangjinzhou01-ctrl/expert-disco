# THRESHOLD / Atelier finish kit

Original modeled detail assets, generated by `scripts/build-atelier-assets.py` with Blender 4.3.2. The editable `threshold-atelier-finishes.blend` retains separate furniture parts, lettering and continuous surface inlays. Raw GLBs are retained under `assets/source/orbital/chunks/`; deployed GLBs use Meshopt.

`src/chapter/world/atelier-layout.json` is the single source for the eight furniture hulls and their authored positions/dimensions. The Blender builder and Rapier constructor read the same file. Benches are conservative solid collision hulls; the space below their seats is too low for the player's prone capsule. The three streaming cells have matching cheap furniture silhouettes and reuse the existing local PBR maps.

The curved coping follows the original CR1 3.2m quarter-circle; it is a thin surface finish, not a new walkable support or an extra gravity route. Small floor inlays are raised only within the controller skin tolerance. The original support/collision mesh is retained.

The new parts have real bevel geometry, weighted normals, metre-scale UVs and coarse local vertex occlusion. This is not a baked global-illumination/lightmap solution. Compressed topology, bounds, UVs, normals, bytes and hashes are checked by the asset tests.

Rebuild after changing the shared layout:

```sh
npm run assets:atelier
```

The builder uses the locally supplied Manrope font for physical lettering. Manrope and Instrument Serif are distributed with their SIL Open Font License files in `public/assets/atelier/fonts/`. Upstream: [Google Fonts Manrope](https://github.com/google/fonts/tree/main/ofl/manrope) and [Instrument Serif](https://github.com/google/fonts/tree/main/ofl/instrumentserif). Existing photographic maps retain the separate ambientCG CC0 provenance in `docs/ORBITAL_MATERIAL_SOURCES.md`.
