# THRESHOLD V0.3 — GRAVITY FREEDOM
## 连续空间、重力场与自由移动设计基线（设计提案 D1）

**状态**：体验拓扑与物理规则设计提案；不是完成建模、碰撞证明或最终坐标冻结。  
**依据**：用户上传的 `expert-disco-threshold-v02.zip`；重点核对 `ChapterController.ts`、`GravitySurface.ts`、`ChapterPhysics.ts`、`InputManager.ts`、`ChapterPersistence.ts`、`WorldRegistry.ts`、CR1 审计与现有建筑碰撞盒范围。  
**本阶段不写 Codex 执行提示词，也不改动源仓库。**

### 1. 不可妥协的目标

1. 角色自由决定路线、方向、速度、是否停下与反向；无定时过场、强制摄像机翻转、假传送或镜头替代物理。
2. 重力变化成为世界的普遍建筑语法，不集中于 INVERT 唯一一处；至少四条可自主选择的闭环，设计目标为十二处具有感知差异的重力节点。
3. 按键支持移动、跑、跳、蹲、趴；零重力可上升、下降、制动。角色真实碰撞体与眼睛高度同步。
4. 两种体验档案：**建筑探索**（尊重作者设计的重力场）和**自由实验**（用户可调速度、跳跃、重力强度；不会禁用安全碰撞）。
5. 保留现有原始门界、VESTIBULE 和 INVERT 的可逆路线，尤其 CR1 的 P0–P6、P4A、C1–C3、全身旋转和出口安全原则。
6. 美学以克制的纪念性建筑体量和可辨识的原世界轴线为中心；既有轨道素材可作为远景对照，不喧宾夺主。

### 2. 空间拓扑（逻辑冻结，坐标尚待实机求证）

[VESTIBULE / 起始大厅] ----- [前厅墙面支路] -------------------┐
           |                                                |
           +-------------------- [主门界] <------------------+
                                     |
                           [INVERT / 中央枢纽]
                             /      |        \
                [原有重力弧]  [交叉重力厅]   [低重力升降中庭]
                     |         |              |
                [墙上平台]-----+         [零重力舱]
                     |                         |
               [顶面行走廊]----[360°螺旋]------+

**四条可闭合回路**（不允许依赖重生/传送命令完成闭合）：

- 回路 A / 入门前的预告：VESTIBULE 主大厅 → 小角度倾斜支路 → 墙面观景台 → 回主大厅。让玩家进入主门之前就第一次察觉世界可以改变。
- 回路 B / INVERT 主叙事：中央枢纽 → 保留原 CR1 弧面 → P4A 墙上着陆 → 原 P5/P6 终端 → 由不破坏 P6 端部防护的**另设分岔连接口**进入顶面走廊 → 返回枢纽。P6 原路线仍可完全原路倒退。
- 回路 C / 多轴对视：中央枢纽 → 左右交叉重力桥 → 螺旋廊 → 回枢纽。不同桥面上的重力方向不同，视觉上同时出现水平、垂直和倒挂的建筑线索。
- 回路 D / 重力幅值体验：中央枢纽 → 低重力跃台 → 零重力中庭 → 带制动的再附着缓冲舱 → 回枢纽。

**十二处重力节点，按路径分布而非孤立六关**：

| 节点 | 所属 | 差异化事件 | 设计要点 |
|---|---|---|---|
| G01 | A | 地面 → 斜面（30°） | 入口前示范，清晰可逆 |
| G02 | A | 斜面 → 墙面（90°）→ 地面 | 建筑支路往返，不阻断主门 |
| G03 | B | 现有 INVERT 0–90° | 使用已经证明过的参数曲面，原范围暂不改 |
| G04 | B | 墙 → 顶（90–180°） | 另一套独立曲面，非复制模型装饰 |
| G05 | B | 顶 → 侧墙（180–270°） | 允许倒挂视角，身体持续有支撑 |
| G06 | B | 侧墙 → 地（270–360°） | 形成真实空间闭环 |
| G07 | C | 朝左 90° | 相邻走廊分别拥有自己的局部 up |
| G08 | C | 朝右 90° | 与 G07 视觉互见、运动不互相干扰 |
| G09 | C | 螺旋首段 0–180° | 玩家可在任意角度停下、后退 |
| G10 | C | 螺旋次段 180–360° | 一圈结束，不改变世界模型方向 |
| G11 | D | 1g → 0.33g → 1g | 通过跳跃跨越高差，惯性连续 |
| G12 | D | 0.1g → 0g → 恢复重力 | 提供上下推进、刹车与安全复位 |

节点数量是内容规划目标，不表示十二套孤立物理实现。应以**可复用重力场/支持图**驱动所有节点。

### 4. 重力场数据结构与过渡规则

建议把现有依赖单一 `s` 参数的姿态逻辑扩展为：

- `GravityVolume`：指定局部重力矢量、强度、过渡宽度和可选择的零重力运动状态。
- `GravitySurfaceChart`：可行走曲面内禀参数、脚底点、切向基、实际支持法线与期望身体四元数；弧/墙/顶/螺旋使用同一契约。
- `GravityResolver`：根据有效碰撞支持、玩家所在体积及显式作者优先级给出**唯一**目标重力，不采用不稳定的任意求平均来解决彼此对抗的重力场。
- `LocomotionState`：`GROUND_WALK / AIRBORNE / CROUCH / PRONE / ZERO_G / REATTACH / RECOVER` 的状态与条件；姿态和所处重力模式分层管理，避免混成一种枚举。
- `OrientationFrame`：玩家的稳定上方向、面向基和最近有效切向；奇异角度回退到前一帧稳定朝向。

**转换行为**：

1. 有可靠接触时，以支持面内禀参数和真实碰撞法线作为方向依据；脱离地面后由当前有效空间重力体积控制抛物运动，不自动吸回曲面。
2. 接触边界使用可测的滞回和最短驻留规则，避免单个重力切换边缘来回抖动；同时保证高速穿越时不是强行卡住玩家。
3. 位置连续，速度按物理积分连续；改变重力不清零动量。贴地转换仍要符合真实碰撞约束。
4. 玩家 up/body 真旋转；摄像机跟随有舒适度设置，但不能以摄像机假旋转替代碰撞旋转。
5. 失重时保留最后稳定姿态；提供相对观察方向的推进/反推进和明确制动，恢复重力时避免姿态瞬间翻跳。
6. 传送门保留原 G0 原子穿越语义；必要时将速度和朝向按门映射一起变换，不允许趴着穿门的出口与障碍重叠。

### 5. 角色体型与操作（初始调校值，不是已经实测的物理参数）

| 项目 | 建议初值 | 允许范围 / 行为 |
|---|---:|---|
| 站立体型 | 高 1.74m，半径 0.30m | 沿用原始胶囊以保证原路线 |
| 蹲姿体型 | 高约 1.10m | 蹲下真实收缩碰撞体，起身之前测净空 |
| 趴姿体型 | 高约 0.52m，纵向约 1.25m | 改用水平朝向的胶囊或等效复合碰撞，身体和摄像机跟随 |
| 普通移动 | 3.0m/s | 可调 1.5–7.0m/s，保持加速/减速曲线 |
| 蹲走移动 | 1.6m/s | 可随基础速度按比例调整 |
| 匍匐移动 | 0.7m/s | 不能沿普通站立路径高速穿行 |
| 跳跃高度 | 以 **1g 下 1.2m** 为基准 | 1g 基准高度可调 0.3–3.0m |
| 低重力 | 默认 0.33g | 真实提升滞空时间与最大跳跃高度 |
| 零重力 | 0g | 切换成方向推进、上下推进、刹车；常规跳跃失效 |

**跳跃计算注意**：如果用户设置“1g 标称跳高 1.2m”，地面起跳速度取 `v0 = sqrt(2·9.81·1.2) ≈ 4.85m/s`。进入 0.33g 时**不重算较小的起跳速度**，理论无障碍跳高约 `1.2/0.33 ≈ 3.64m`；垂直动量和地面支持状态决定具体效果。`0g` 下不出现“无限跳高”数值，改为推进。高度和重力均应按复杂碰撞和安全设计限幅。

**姿态转移准则**：`站立↔蹲↔趴` 只能在连续 swept-collision 查询允许时执行；无法起身时停留当前姿态并告知“头顶空间不足”，不可穿墙、摄像机穿顶。墙上和天花板上的“趴”以当地 up 为竖直参考，不以世界 +Y 为参考。

### 6. 键鼠和移动触控契约

- 键鼠：WASD 移动；鼠标观察；Shift 冲刺；Space 跳（失重时推进上升）；Ctrl 蹲（失重时推进下降）；Z 切换趴；R 安全复位；E 互动；P 摄影。需要考虑现有键位冲突与可重绑定。
- 手机横屏：左摇杆 + 右视区 + 独立跳 / 蹲 / 趴键；失重状态将跳/蹲映射为上/下推进，并提供可触达的制动键。`冲刺` 使用可配置点按切换或按住。
- 操作 UI 需独立 pointer capture，至少可同时识别左摇杆 + 右观察 + 一项动作；按键应有 ≥44 CSS px 有效触控区域，可自定义位置/大小/透明度，遵循安全区与横屏长宽比。操作控件不拦截右侧观察区域。
- 跳跃提供输入缓冲和离边缘宽限（设计提案各 80–120ms）；可开关的自动冲刺和蹲/趴切换，不假设用户只有键鼠。
- 摄像机滚转速度、减弱晕动选项和局部 horizon UI 可调；减少晕动不得改变胶囊物理姿态。

- 旧 `GravitySurface.ts` 不直接复制 12 份。抽出曲面图与重力决策，并保留旧 INVERT 兼容适配和基准测试。

- `InputManager.ts` 的仅二维移动接口扩展为 `axes + actions + justPressed/held`，统一键鼠触屏；保留 G0 LAB 旧输入兼容。
- `ChapterPersistence.ts` 保存设置版本升级、按旧版本迁移；检查点升级需记录重力区域、姿态、速度等，并对旧 v1 保存兼容，不可悄悄清空用户存档。
- 建筑增量资产分区加载，物理支持体与实际可见建筑同源；手机渲染性能必须通过真实设备的长时间回归验证。

### 8. 工程验收门槛

1. **原有能力**：CR1 P0–P6 前进与逆向、P4A 的真实安全着陆、传送门双向穿越、C1/C2/C3 的可见性与已有 G0/LAB 测试全部维持。
2. **空间自由度**：十二节点可分别自由正行、逆行、暂停、对角输入，四条逻辑闭环可连续走通，且不靠重生/瞬移。
3. **物理安全**：每种姿态在各个有支持平面完成形状 sweep，不能起身穿过天花板、快速穿过接缝、倒挂穿门坠落；冲突时返回最近有效安全接触点而不是无提示重置所有进度。
4. **跳跃/失重**：不同 g 的离地高度和滞空时长符合设计容差，跨场边界保持动量；失重推进、制动、再附着可用。
5. **输入**：PC、19.5:9 与 20:9 安卓横屏下多指操作和全部动作键可用，暂停/失焦后不会残留按住状态。
6. **呈现**：至少三处原始世界轴线同时进入画面的强记忆点；不能靠只旋转天空盒或镜头作弊。
7. **性能与可访问性**：移动端提供可观察帧时、物理成本和内存趋势。帧率目标需指定目标机型再实测，不以桌面 E2E 冒充安卓真机验收。
8. **验收材料**：自动化物理/输入/可见性测试、四条连续无剪辑可逆通行视频、移动端 10 分钟长时实测、实际源资产坐标和碰撞审计报告。
