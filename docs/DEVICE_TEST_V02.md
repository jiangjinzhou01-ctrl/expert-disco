准备：在主机运行 `npm ci && npm run build && npm run preview -- --host 0.0.0.0 --port 4180`。手机与主机同网，打开 `http://主机IP:4180/?debug=1`；云环境使用真实端口转发地址。先确认 WebGL2；不要将构建文件复制到手机 file:// 打开。

记录手机型号/SoC/RAM、Android与Chrome版本、浏览器完整UA、屏幕像素/方向、DPR、画质与是否省电模式。默认平衡；高/节能只改实时门内分辨率。关闭其它图形任务。

10分钟内完成：

1. 进入窄廊并绕坑到门侧，左右移动看实时视差，穿门进入INVERT。
2. 找到侧向重力黑色物体，观察真实落向侧墙和撞击。
3. 弧面0°、约45°、90°分别停住、左右观察、倒退；保持左指移动时右指滑动仍有效。
4. 站墙、越过P4A开口、到终端并触控激活，原路回到正常地面再穿回前厅；至少完成5次往返。
5. 持续转动视角，横竖屏切换、切后台30秒再恢复；松指后不能持续漂移。若系统取消指针，重新触摸能继续。
6. R等价安全复位、设置中的章节重启、减少镜头运动选项均检查；确认身体碰撞方向不被减少运动改变。
