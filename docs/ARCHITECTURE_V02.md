# THRESHOLD V0.2 架构与资产管线

本工程从现有 G0 工作树扩展，没有替换其数学、分段穿越和独立 LAB。输入权威顺序为本轮 master、CR1、原空间冻结；参考图用于构图审查，未进入运行时。

## 世界与所有权

`App.tsx` 按 URL 只挂载一个体验：默认 `ChapterView`，或 `LabApp`。R3F 的单个 `useFrame(...,1)` 接管渲染；没有第二个 RAF、物理 interval 或 React 每帧位置 state。React 每 200ms 更新一次诊断 UI。

| `ChapterScenes` | GLB 加载、独立 Three Scene、PBR 材质、静态光影、批处理与释放 |
| `GravitySurface` | 同源曲面的内禀参数、脚底/身体/眼睛、四元数与重力数学 |
| `ChapterPhysics` | 唯一 Rapier World，固定/运动学/动态实体、真实胶囊查询与提交 |
| `ChapterController` | 局部 Up 输入、支持接触、自由二维表面运动、失去支持后的落体、检查点与互动 |
| 原 `PortalMath` | 纯数学，沿用 G0 全部不变量与非法输入校验 |
| 原 `PortalTransfer` | 仍是唯一传送提交者；注入世界门注册和 physics adapter |

VESTIBULE root 为 identity，INVERT root 为平移 `(100,0,0)`。两个 Three Scene 真正独立；一个 Rapier World 中的固定碰撞体互不重叠，查询进一步按世界元数据过滤。root 目前只使用平移；保留 Matrix4 使归属明确，不声称支持任意旋转缩放的世界。

## 门数学和连续提交

右手系，+Y 为上，门局部 +Z 为正面；进入是正侧到负侧。

`T = M_destination * Ry(pi) * inverse(M_source)`。

前厅门 `(0,2.8,-20), yaw=0`；INVERT 局部门 `(0,2.8,18.2), yaw=pi`。这对门映射为平移 `(100,0,38.2)`；LAB 保留含真实 90°方向映射的原对门。净洞 3.6×5.6 与模型一致，8m 是外框高度。

G0 分段传送算法原样承担：源世界真实碰撞 → 实际跨面轨迹 → 胶囊有效洞口 → 映射和出口安全查询 → 一次原子归属提交 → 目标侧剩余位移碰撞。状态机由位置和方向重新武装，没有固定冷却秒数。

物理适配接口 `PortalPhysics` 避免将新世界硬塞进旧房间构造器。新增出口合法地面接触钩子，仅允许已标记 walkable 的轴对齐盒体，且真实胶囊底部在顶面之上；扩大安全查询形状接触地面不等于埋入墙体。WASM query predicate 中只读预先计算的 handle 集合，不在借用期间再次调用 Rapier 几何 getter。回归覆盖合法地面与真正地下胶囊的区别。LAB 没有该钩子，继续使用原严格策略。

门位于正常重力区域；只有退回 `NORMAL / Up=(0,1,0)` 后才能到达它。不会把横躺胶囊交给 G0 的 yaw 门算法。

## 支持面与真实重力

弧面半径 3.2，θ=0..pi/2：

```
foot = (1.5 + 3.2 sinθ, 3.2(1-cosθ), z)
up = (-sinθ, cosθ, 0)
g = -9.81 up
body quaternion = axisAngle(+Z, θ)
body centre = foot + (.87 + .006) up
eye = foot + 1.55 up
```

物理胶囊是 `Capsule(.57,.30)`，总高 1.74m。6mm 为身体接触 skin，眼睛仍严格采用 CR1 脚眼公式。物理刚体的四元数确实旋转；没有锁定旋转后单独滚转镜头。

曲面坐标 `(s,z)` 是可独立移动的二维支持图，s 在地面、128 段弧面及墙面之间连续，**没有按时间走路线、按触发器播放弧线动画的实现**。输入先经 yaw 与 body quaternion 转到当前切平面。固定步运动的每小段都做真实支持射线；弧段 θ 由有效接触修正，法线点积不合格拒绝。入口使用1mm内侧激活边界；曲面 s 连续，离开回到 s≤0 才恢复 NORMAL，避免在接缝重复切换。

Rapier KCC 只处理平移。自定义旋转 sweep 将中心位移与四元数插值分段到 ≤约1cm/0.0034rad；对旧姿态做连续 castShape、对新姿态做重叠验证，再用正确 setUp 的 KCC 检查位移。胶囊中间线段半长 .57m，最大旋转偏离小于 `.57 * .0034 = 1.938mm`，查询半径额外2mm覆盖中间方向。回归测试让两个端点都安全但中间旋转碰到障碍，保证不是端点冒充扫掠。

停住时支持约束提供重力反力；离开支持面后显式积分 `v += g*dt`，由旋转胶囊碰撞限制落体。没有把玩家钉在固定世界高度。普通地面通过 KCC 下压/落体和 autostep 处理低台阶；桥和绕行均是真实可走体积。

统一 Rapier 世界重力为零。玩家的重力在控制器内按支持/落体约束应用；黑色动态见证物是 dynamic rigid body，每物理步施加 `mass * (9.81,0,0)`，真实撞向接收墙。每8个模拟秒复位该展示物以重复观察；此复位只属于展示物，记录次数，从未用于搬运玩家。

## 调度与容错

每帧：输入 → 累积器（delta≤.25s）→ 最多5次1/60s物理步 → 角色候选位移/碰撞/必要的原子传送 → 提交身体位置和四元数 → 显式动态物受力并 world.step → 相机/装置从完整状态同步 → 目标 Scene 实时 render target → 主 Scene → 性能观察。

长帧超过预算的时间计入 droppedSeconds，避免无限追赶；因此很慢的软件渲染会表现为模拟推进慢，不伪造60Hz实时性能。跨门不做跨世界线性插值。运动学重新定位同时写当前和 next translation/rotation，清零虚假瞬移速度。

静止NORMAL角色每个物理步也更新KCC接触，避免沿用上一次computedGrounded而在下楼停住后悬空。最近有效支持检查点每120步更新。R 安全回退保留世界和真实重力姿态；“返回章节起点”明确重新开始装置状态。NaN、失去支持过久与跌落触发带原因恢复。

## 建模、PBR 与光照

`build-v02-assets.py` 通过 Blender 4.3.2 headless 生成真正的带厚度建筑：压缩走廊、中庭/中央坑、悬挑和肋、门框内衬、可通桥、台阶、切口与凹槽、窗/栏杆、同源弧面和后墙。源 .blend、PNG 与 GLB 都实际存在。资产 ID、bounds、origin、triangles、materials 写入 manifest；盒形 collider 与支持闭合壳 trimesh 写入独立 JSON。视觉 bevel 与简化盒代理有毫米至厘米级边缘差异，不使用复杂装饰网格作动态碰撞。

源模型沿用 +Y 向上，导出关闭 Blender exporter 的轴重映射；运行与碰撞使用相同数值坐标。测试直接解码 GLB 验证支持顶点对应碰撞数据，而非只对两个复制 JSON 做比较。正面支持与0.55m背侧、外周端盖共同构成闭合壳；接缝先按坐标焊接，内部边不加端盖。单元测试验证每条无向边恰有两个三角面，物理测试从背面靠近，防止走进可见厚度。源.blend把两个局部原点相同的世界放在各自命名Collection中；默认显示VESTIBULE，编辑INVERT时切换Collection可见性。

6种非透明 PBR 材质有256² base color、roughness、normal 贴图，GLB 内嵌；玻璃是有框架和实心碰撞的透明材质。纹理按实际米制 UV 缩放，2段倒角，离线 BVH 射线局部 AO 进入顶点色。**这是局部 AO，不是完整路径追踪 GI 或光照贴图。**

两场景预加载完才进入可玩状态，穿门时不下载世界。不可移动建筑按材质批处理，三个原始轴线见证体和支持面保留对象名以便实际遮挡射线审查。使用 ACES 色调映射、PMREM 中性反射和受控天空/环境光；两道1536静态阴影图只在初始化/上下文恢复时生成。没有 Bloom、图片背景和后期画面遮挡。

## 实时渲染与资源

沿用主/映射相机同投影与 gl_FragCoord 屏幕采样、出口全局 clipping plane、目标门面隐藏和 try/finally 状态恢复。每帧最多1个门内 pass。背对/视锥之外的门为0 pass。离屏分辨率按覆盖范围分档并保持视口宽高比；避免连续像素尺寸波动和“每帧先扩大再缩小”的重建。`targetResizes` 可观察，固定镜头回归断言连续绘制不重建。

RenderTarget、几何、全部材质贴图、shadow map、PMREM 与 Rapier world 按所有权释放。Context restore 重新生成反射环境和静态阴影，目标纹理重新分配。主像素比上限1.25。画质选项只调整实时目标分辨率，不替换成静态图。

性能数据是 CPU 帧间隔/CPU 物理时间、draw count 与已知 GL 资源数。GPU query 未采集，显示不可用；未测得完整显存字节，不能用 Three 的纹理数量声称显存占用。

## 当前美术方向参照与可见性验收

INVERT增加原+Y重力的19个0.22m实体踏步与合并最后一级的4.4m高廊台，正常胶囊可以真实上下往返；站墙后这些构件成为横向参照，不需要旋转整个场景。新构件X不超过2.55，墙行胶囊最小X约2.954，保留实体间隔。

GLB extras保存asset_id。按材质合批时记录face index区间到该ID的映射；32×18条相机射线统计第一个不透明真实三角面。C3同时要求两件旧轴线各≥8样本、实际支撑墙≥6、旧楼梯≥8；保留450表面样本检查作为补充，避免巨大近距构件裁切时用AABB抽样数替代可见画面面积。此昂贵查询仅用于显式开发观察/测试，不进入正式逐帧模拟。
