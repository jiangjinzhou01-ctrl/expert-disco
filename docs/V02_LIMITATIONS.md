# V0.2 限制与未验证项

**总体 PARTIALLY VERIFIED。** 自动化通过范围与实际数据见 V02_TEST_REPORT，不能将软件渲染和触控模拟当成真实设备验收。

1. **真实设备覆盖 BLOCKED**：当前只有 Linux 云容器的 Chromium/SwiftShader。没有连接真实桌面 GPU、中端/高端 Android、iOS 或头显。Android 10分钟持续运行、温升/降频、系统前后台与真实触控驱动差异没有通过。交付有完整测试入口与导出步骤。
2. **美术等级有限**：实际可维护 Blender/GLB/PBR 建筑已交付；不是图片替代场景。离线局部射线 AO 加环境近似并非全局间接光烘焙；不能称为建筑摄影品质认证。C3的近距离结构仍会裁切远端；新增旧重力楼梯与屏幕区域首命中检查后，实际支撑、两轴和转横楼梯可同时读出，但没有把完整20m巨柱收进单张图。阴影分辨率与直接光的局部硬边可以在截图看到。
3. **软件帧率慢**：SwiftShader 执行两场景 PBR 与阴影时可能出现显著长帧，固定步最多5次追赶会导致游戏时间慢于墙钟。没有编造60FPS。真实GPU性能尚不能由这些数值推断；完整JS/WASM与未压缩GLB仍有体积优化空间。
4. **局部重力适用范围明确**：本章支持地面→当前连续弧面→墙面这个二维支持图，并非任意网格自动攀爬或任意重力体积求解器。角色是运动学胶囊，有支持约束和显式落体；动态见证物是真刚体受力。角色没有跳跃，不支持自由飞行。
5. **门户仍遵循 G0 边界**：一对固定、无缩放、只绕Y旋转的门；没有无限递归、任意倾斜门、重力旋转门、携带大型动态物跨门或跨世界物体连续接触。进入门前必须恢复正常重力。LAB 保留原方向映射和全部旧测试。
6. **碰撞代理简化**：建筑用同源盒代理，弧面/支撑用真实三角网格。倒角装饰的精细边缘与盒代理存在毫米至厘米级差别；本章已测通行洞口、台阶、桥、窗、护栏和返回路线。未声称对所有任意速度、任意用户输入组合做穷尽证明。
7. **显示/照明**：静态阴影只初始化/恢复时生成，移动展示物没有每帧更新的独立投影阴影；玻璃是低成本透明着色，不是折射/路径追踪玻璃。没有音频系统、完整导航/无障碍、手柄或高级图形后处理。
8. **性能诊断边界**：GPU 时间未采集；纹理/几何/程序数不是完整显存字节。帧间隔含浏览器/系统调度，物理耗时是CPU值。没有将某个指标冒充其他指标。
9. **测试隔离**：开发/e2e 构建才有可写确定性接口与几何观察按钮；正式构建仅提供只读快照。只读快照内容是副本。测试机位可瞬间定位用于构图验证，但完整路径测试和生产实录从真实出生点输入驱动，没有使用这些定位接口。
10. **远程状态**：本轮在独立 threshold-v02 分支/工作树交付，没有向 GitHub 推送或覆盖已上线 G0。GitHub Actions 配置可复现，本轮远程CI执行未经验证。

当前适合作为可玩首章和进一步工程验证的基础。ECHO/DRIFT 可以复用世界注册、门户渲染与资产边界；在将其列为正式V1基础前，必须完成真实硬件性能验证并继续精细化光照/摄影完成度，且不能假定当前支持图已解决任意世界的重力和碰撞。
